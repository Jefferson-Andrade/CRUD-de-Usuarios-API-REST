**CRUD de Usuários — Java + Spring Boot**

Desenvolvimento de uma API REST para gerenciamento de usuários, utilizando **Java, Spring Boot, Spring Data JPA e PostgreSQL**, com ambiente de desenvolvimento e banco de dados configurados via **Docker Compose**. Implementação das operações de **criação, consulta, atualização e exclusão (CRUD)**, seguindo organização em camadas e boas práticas de desenvolvimento backend.

**Tecnologias:** Java • Spring Boot • Spring Data JPA • PostgreSQL • Docker • Docker Compose • Maven • REST API • Git/GitHub
